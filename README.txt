紅華祭 案内マップ作成プログラム（新レイアウト版）
================================================

添付された仕様txtとPowerPointの5画面をもとに編集画面を変更しています。
既存の校内マップ、画像素材、登録データを含めてあります。

【起動】
1. ZIPをすべて展開してください。
2. koukasai_map_builder フォルダーの start_editor.bat をダブルクリックします。
3. 編集画面 http://127.0.0.1:5001/ が開きます。
   初回に必要なパッケージをインストールします。setup.batからも実行できます。

Python 3.10以降が必要です。元の環境で使用していたPython 3.11でも利用できます。
必要なパッケージは requirements.txt に記載しています。

【ピンの作成】
・上部の「標準ピン」を押し、カテゴリーを選んで「OK」を押します。
・ピンのカテゴリーは、ポリテクフェスタ（ピンク）、紅華祭（オレンジ）、模擬店（緑）です。
・ピンはマップ中央に初期サイズ40で配置されます。
・ピンの番号はカテゴリーごとに1から、空いている番号を自動で付けます。
・ピンをドラッグして位置を決めます。
・位置はマップ画像に対する割合で保存します。画面のサイズが変わっても位置を維持します。

【大きさの変更・ピンや施設画像の削除】
・変更したいピンまたは画像を1回クリック／タップします。
・右上の「サイズ」に数値を入力するか、－／＋を押します。範囲は28〜260です。
・右上の「位置固定」にチェックすると、そのピンまたは画像を動かせなくなります。
・ピンや施設画像を右下のごみ箱までドラッグし、指・マウスを離すと削除確認を表示します。
・ピンを削除すると、そのピンに登録した企画情報もまとめて削除されます。
・ごみ箱へドラッグした場合も、ごみ箱をクリックした場合も、確認後にだけ削除します。

【ピン番号の振り直し】
・右上の「番号振り直し」を押します。
・全カテゴリーまたは指定カテゴリーを選べます。全カテゴリーの場合も、各カテゴリーで1から始まります。
・自動割り当ては、現在のピン登録順で番号を振り直します。
・手動割り当てはカテゴリーを指定した場合のみ選べます。
・手動では、1番にしたいピンから順番にマップ上で押します。全ピンを押すと「完了」を選べます。
・「取り消し」を押すと、振り直す前の番号に戻ります。

【ピンに企画アイコンを追加】
1. ピンをダブルクリックします。タッチ操作では同じピンを素早く2回タップします。
2. 左側に、そのピンに登録したアイコン一覧が表示されます。
3. 「アイコン追加」を押してPC内の画像を選択します。
4. 左側の詳細設定に、企画・展示名、学科、学年またはその他団体、場所、階、説明文を入力します。
5. 「決定」でそのピンに登録します。1つのピンに複数の企画を登録できます。

詳細設定の必須項目:
・企画・展示名
・学科: 専門機械、専門電気、専門電子、応用機械、応用電気、応用電子、その他
・通常の学科を選択したとき: 学年（1、2）が必須。その他団体は入力できません。
・その他を選択したとき: その他団体が必須。学年は入力できません。
・学科が未選択のとき: 学年とその他団体は薄い色になり、入力できません。
・場所: 1〜9号棟、本館、体育館、屋外
・階: 場所が1〜9号棟または本館のときだけ必須（1〜4階）。体育館・屋外では入力しません。
・説明文

【編集・取り消し・アイコンの削除】
・一覧でアイコンを選択し「編集」を押すと詳細設定を開きます。
・「決定」までは仮入力です。編集内容が途中で元の企画に反映されることはありません。
・「取り消し」で、新規登録は中止、既存の編集は変更前に戻ります。
・新規登録を取り消した場合、ピンにはアイコンを登録しません。
  選択時にアップロードした画像ファイル自体は、再利用できる素材として残ります。
・一覧でアイコンを選択し「削除」を押すと、画像と企画名を確認画面に表示します。
  もう一度「削除」を押した場合にだけ、その企画を削除します。
・詳細入力中はマップ操作と全体保存を止めています。「決定」または「取り消し」で戻ります。

【施設案内の画像】
・上部の「画像追加」を押してPNG／JPEG／WebP画像を選ぶと、中央に配置します。
・画像を選んだあと、施設名と場所を入力して「決定」を押します。
・施設案内は「画像追加」から登録します。施設画像をダブルクリック／ダブルタップすると、一覧を経由せず施設名・場所の編集画面を開きます。
・ドラッグで移動し、右上でサイズ変更、ごみ箱へのドラッグで削除できます。
・施設画像の初期サイズは64です。施設名には画像のファイル名を使用します。
・画像はすべてPC内のファイルから追加します。
・画像は透過PNGの透明部分をそのまま保持します。

【フロア図の編集】
・上部の「フロア図編集」を押すと、専用の編集画面を開きます。
・1号棟1〜4階、2号棟1〜2階、3号棟1〜2階、5号棟1〜2階、本館1〜3階を編集できます。
・左上で編集するフロアを選び、企画一覧・画像ファイル追加・文字追加から配置します。
・設備・入口の一覧とサイズ横の削除ボタンはありません。削除にはごみ箱を使用します。
・企画は、編集画面の詳細設定で場所と階を登録すると、該当するフロアの一覧に表示されます。
・追加した要素はドラッグで移動し、右上でサイズ変更・位置固定、ごみ箱へのドラッグで削除できます。
・「画像を追加」で任意の画像を配置できます。「文字を追加」で案内文を配置し、ダブルクリックで編集できます。
・右上の「保存」を押すと、校内マップとフロア図をまとめて保存します。
・案内画面で企画を選ぶと、その企画があるフロア図を校内マップ上の設定した位置に表示します。
・校内マップ編集画面の「フロア案内枠」を押すと、案内画面に表示する枠の位置と大きさを変更できます。
  青い枠をドラッグして位置を調整し、右上の「幅(%)」で大きさを変更します。
・「フロア案内枠」をもう一度押すと、青い編集枠を閉じます。

【保存と案内画面】
・最後に、右上の「すべて保存」を必ず押してください。
・詳細設定の「決定」は編集中のマップへの反映です。ファイル保存は「すべて保存」で行います。
・「案内画面を確認」では保存済みの内容を開きます。
・保存すると、起動中の案内画面へ約15秒以内に反映されます。
・1つのピンを押すと、そのピンに登録した企画を一覧表示します。
・企画を押すと、担当学科・学年または団体、場所・階、説明を表示します。
・カテゴリーの企画一覧はピン番号ごとに分けて表示します。
・マップでピンを選択しても、同じカテゴリーのほかのピンは表示されたまま選択できます。
・カテゴリーやピンを選択中も、別カテゴリーのピンは薄く表示され、そのまま選択できます。
  薄表示のピンも位置と種類を確認できる濃さで表示します。
・校内マップのピン以外を押すと、「すべて」表示に戻ります。
・施設案内は、同じ名称の設備を1種類としてまとめて表示します。
・公式情報は、カテゴリーが「すべて」のときだけ表示します。
・選択中のピンはカテゴリー色と白の二重枠で強調します。
・模擬店と施設案内では、詳細に待ち時間を表示しません。
・詳細画面の戻るボタンは「戻る」の文字表示に統一しています。
・ピンの一覧から詳細を開いた場合、「戻る」でそのピンの一覧に戻ります。
・保存前のデータは data\backups に自動バックアップします。
・複数の編集画面で同時保存した場合、古い版からの上書きを防ぎます。
  保存エラーが出たときは表示内容を確認し、別の編集画面の保存状況も確認してください。

【既存データの引き継ぎ】
・元ZIPの外側の koukasai_map_builder にあった最新データを使用しています。
・重複していた内側の同名プロジェクトは含めていません。
・旧データの企画用マップ画像は、同じ位置・サイズのピンと、そのピン内の企画アイコンとして読み込みます。
・施設画像はそのままです。企画名、説明、画像、従来の待ち時間の情報も引き継ぎます。
・旧データにない学科・号棟などの情報は推測して埋めていません。
  既存企画を編集するときに新しい必須項目を入力してください。
  未編集の既存企画は、そのまま移動・全体保存できます。
・初回の「すべて保存」で新形式（schemaVersion: 4）を保存します。
  旧プログラムから新形式を編集しないでください。元データは自動バックアップで保持します。

【案内画面の起動】
・start_main.bat: 来場者向けサーバーを起動
・start_all.bat: サーバー起動とこのPCでの全画面表示
・open_local_viewer.bat: 起動済みサーバーの案内画面をこのPCで全画面表示
・open_remote_viewer.bat: server_address.txtに指定したPCの案内画面を表示

案内画面: http://127.0.0.1:5000/
別PCから: http://サーバーPCのIPv4アドレス:5000/
編集画面: http://127.0.0.1:5001/ （サーバーPC内で使用）

別PCでは同じ学校内ネットワークに接続してください。
サーバーPCのIPv4アドレスは、コマンドプロンプトの ipconfig で確認できます。
server_address.txt に実際の案内画面URLを1行で記入してください。
Windowsのファイアウォールは、学校の管理方針に沿って接続を設定してください。
全画面の終了は Alt+F4、Pythonサーバーの終了は黒い画面で Ctrl+C です。

【インターネット公開（GitHub Pages）】
来場者向け案内画面を、学校外のスマートフォンやPCからも見られるように公開できます。
公開されるのは案内画面だけです。編集はこれまで通り、このPCの編集画面で行います。

更新の手順:
1. 編集画面で内容を変更し、「すべて保存」を押します。
2. publish.bat をダブルクリックします。
   docs フォルダーへ案内画面を書き出し、GitHubへ送信します。
3. 数分後に公開中の案内画面へ反映されます。

公開URL: https://GitHubのユーザー名.github.io/リポジトリ名/

初回だけの準備:
1. github.com で新しい Public リポジトリを作成します（READMEなどは追加しません）。
2. このフォルダーで次を実行します。
     git remote add origin https://github.com/ユーザー名/リポジトリ名.git
     git push -u origin main
   初回はブラウザでGitHubへのログイン画面が開きます。
3. リポジトリの Settings → Pages → Build and deployment で
   「Deploy from a branch」を選び、Branch を main、フォルダーを /docs にして Save を押します。

注意:
・Publicリポジトリのため、プログラム、案内データ、画像は誰でも閲覧できます。
・data\backups、data\image_originals、server_address.txt はGitHubに送信しません。
・docs フォルダーは publish.bat（export_static.py）が毎回作り直します。直接編集しないでください。

【主なファイル】
editor.py                 編集画面サーバー
main.py                   来場者向け案内画面サーバー
storage.py                データ読込・保存・旧形式変換・入力検証
export_static.py          GitHub Pages用に案内画面を docs へ書き出し
publish.bat               書き出しとGitHubへの送信
docs\                     GitHub Pagesで公開する案内画面（自動生成）
static\js\editor.js       編集操作
static\css\editor.css     PowerPointをもとにした編集レイアウト
static\css\editor-revision.css  修正案画像に合わせた上書きレイアウト
static\js\floor_editor.js フロア図の編集操作
static\css\floor_editor.css フロア図編集画面のレイアウト
static\js\viewer.js       来場者向け画面の操作
static\css\viewer.css     来場者向け画面のレイアウト
static\images\library     同梱画像素材
static\images\uploads     追加画像
static\images\maps        校内マップ
static\images\floors      フロア図・フロア図用素材
static\images\ui          背景
static\images\system      QRコード
static\images\thumbs      素材一覧用サムネイル
data\guide.json          現在の案内データ
data\backups             保存前のバックアップ
data\image_originals     追加した画像の元ファイル

編集画面は1600×900の配置を基準に、ウィンドウへ全体を拡大・縮小します。
地図の縦横比を維持し、左側の編集欄を開いても画像全体とピンを同じ比率で表示します。
インターネット上の画像・フォントなどへの接続なしで画面を利用できます。

【データ保存テスト】
必要なパッケージを入れたあと、プロジェクトフォルダーで実行します。
  python -m unittest discover -s tests -v
テストは一時フォルダーを使うため、現在の案内データは書き換えません。
